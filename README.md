# PruebaPractica
Este proyecto es una herramienta interactiva desarrollada en C++ para la asignatura de Algoritmos y Lógica de Programación. El sistema integra operaciones matemáticas básicas y un módulo avanzado de procesamiento de datos académicos mediante la lectura y persistencia en archivos.  
Características Principales:
​Menú Interactivo: Interfaz de consola organizada para una navegación intuitiva entre módulos.  
​Operaciones Matemáticas: Implementación de suma, resta, multiplicación y división con validación de seguridad para división por cero.  
​Procesamiento Automatizado: Lectura masiva de estudiantes desde un archivo alumnos.txt utilizando stringstream y vector.  
​Persistencia de Datos: Generación automática de un reporte final en resultados.txt que incluye promedios y estados de aprobación.  
​Robustez: Manejo de excepciones con bloques try-catch para evitar errores de ejecución por datos mal formateados.  
​📂 Estructura:
​/src: Contiene el código fuente principal (.cpp).  
​/resultados: Carpeta donde se almacena el archivo resultados.txt generado.  
​/capturas: Evidencias visuales del funcionamiento del programa.  
​alumnos.txt: Archivo de entrada con el listado de compañeros y sus calificaciones.  
​Instrucciones
​Preparación: Asegúrate de que el archivo alumnos.txt esté en la raíz del proyecto con el formato: Nombre,Nota1,Nota2,Nota3,Nota4,Nota5.  
​Compilación: Utiliza CodeBlocks o cualquier compilador estándar de C++.  
​Ejecución: Selecciona la Opción 2 en el menú para procesar la lista completa de forma automática.
